# sentinel

Sentinel is a lightweight system monitoring framework intended for homelab environments. It collects metrics from multiple nodes, stores them centrally, and provides both terminal based (TUI) and API based Web access to the data.

## Features

- Lightweight agent: Python agent with no external dependencies (stdlib only)
- Central server: FASTAPI server with PostgreSQL storage
- TUI dashboard: neat and descriptive TUI
- Alert system: configurable alerts
- RESTful API: complete API for external integrations
- Docker support: easy deployment with docker-compose
